# BytesFlipper

A simple **x64dbg** plugin to swap bytes (Big-Endian to Little-Endian, for example).

## Installation

1. Copy BytesFlipper.dp64/.dp32 into your x64dbg `plugins` folder.
2. Restart x64dbg.

## Usage

1. Open **Plugins -> BytesFlipper**.
2. Paste the copied bytes.
3. Click **Flip**.
4. Copy the result.
